# Supplementary evidence navigation

Open 00_READ_ME_FIRST.md, then MANUSCRIPT_DATA_MAP.csv to find a section, figure or table. The complete file index is inside revision_data.zip.

For the dated-corpus comparison, open Supplementary_Data_S16_READ_ME_FIRST.md. The standalone S16 ZIP and its copy inside revision_data.zip have identical contents. Scientific file bytes are preserved, except the active results-guide editorial status correction. ORIGINAL_PATH_MAP.csv records the correspondence.

The portable recalculation entry point runs the original count script in a temporary reconstruction. It makes no provider calls and changes no evidence. The original full-study summarizer requires private research coordination files and is labeled historical execution provenance, not a standalone script.

Current documents and figures are unchanged from v0.3.0. Internal quality records are separate in release_audit/ and should not be uploaded as manuscript supplements.
