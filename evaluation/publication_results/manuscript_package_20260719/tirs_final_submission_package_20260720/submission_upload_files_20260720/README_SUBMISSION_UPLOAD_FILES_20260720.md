## Permission note

The phrase "redistribution check" refers to whether the public repository should include full cleaned copies of ANVISA documents. The source regulations are public, but the safest public-repository approach is to provide official source links, checksums, and cleaning scripts, and include full cleaned source text only if redistribution is acceptable and necessary.

See `source_reproducibility/` for official ANVISA links, raw/cleaned file checksums, and the cleaning script.
